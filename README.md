# Exploratory-Data-Analysis-EDA-Customer-Churn-Dataset-Visualization-Insights

This repository contains an exploratory data analysis (EDA) project using NumPy and Pandas on the Telco Customer Churn dataset. The notebook covers:

Basic NumPy functions for statistical analysis

Data manipulation and visualization using Pandas and Seaborn

Analysis of relationships between categorical features (gender, senior citizen, partner, dependents) and churn

Key analyses include:

Mean, median, standard deviation, variance

Correlation and data distribution

Visualizing churn proportions across categories
